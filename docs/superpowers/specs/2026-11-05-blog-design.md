# vmamore.com.br — personal site (v1) — design

Date: 2026-11-05
Status: approved in chat, pending spec review

## Goal

A minimal, bilingual (pt-BR / en) personal site for Vinicius Mamoré with an
About section and an Experience section, generated by a small F# static site
generator and hosted on GitHub Pages under the custom domain `vmamore.com.br`.

Out of scope for v1: blog posts, photos/logos, analytics, comments, JavaScript.
Posts will be designed later; the structure must not block adding them.

## Hosting and domain

- GitHub repo: `vmamore/vmamore.github.io`, **public** (Pages on the free plan
  requires a public repo).
- Pages source: **GitHub Actions** (no built HTML committed), enabled via
  `gh api` (`build_type: workflow`) when the repo is created.
- Custom domain: `vmamore.com.br`, registered by Vinicius at registro.br
  (~R$ 40/year, CPF required). DNS zone at registro.br:
  - `A @` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
  - `CNAME www` → `vmamore.github.io`
- `static/CNAME` contains `vmamore.com.br` and is copied to the output.
- After DNS propagates: set custom domain in repo settings, enable "Enforce
  HTTPS", and verify the domain in the GitHub account's Pages settings.

## Domain model

```fsharp
type Lang = Pt | En
type Localized = { Pt: string; En: string }   // missing translation = compile error
type YearMonth = { Year: int; Month: int }
type Role =
    { Title: Localized
      Start: YearMonth
      End: YearMonth option          // None = current
      Summary: Localized option      // None = title and dates only
      Tech: string list }
type Company = { Name: string; Dir: string; Roles: Role list }   // Dir = terminal folder name, e.g. "stone"; roles newest first
type Education = { School: string; Course: Localized; StartYear: int; EndYear: int }
type Profile =
    { Name: string
      Headline: Localized
      Location: string
      Links: (string * string) list  // label, url
      Companies: Company list        // newest first
      Education: Education list }
```

## Pages and i18n

- One page per language: `_site/index.html` (pt-BR) and `_site/en/index.html` (en).
- Page sections, in order: header (name, headline, location, links, language
  toggle) → About → Experience → Education → footer.
- Language toggle links to the same page in the other language.
- `<html lang="pt-BR">` / `<html lang="en">`; `<link rel="alternate" hreflang>`
  for both languages plus `x-default` → pt-BR; `<link rel="canonical">`.
- Base URL `https://vmamore.com.br` is a single constant, used for canonical/hreflang.
- Internal links are root-relative (`/`, `/en/`).

### Date and duration rules

- Month format: pt `abr 2025`, en `Apr 2025`. Current role: pt `atual`, en `Present`.
- Duration counts months **inclusively** (matches LinkedIn: Apr 2025 – Dec 2025
  = 9 months; Dec 2021 – Mar 2025 = 3 years 4 months).
- Current roles end at the build month (build date injected for testability).
- Text: pt `1 ano`, `2 anos`, `1 mês`, `3 meses`, `1 ano e 2 meses`;
  en `1 year`, `2 years`, `1 month`, `3 months`, `1 year 2 months`.
- Company span = earliest role start → latest role end (or current).

## Styling — "Terminal", green (chosen 2026-11-05 from the style previews)

Reference preview: https://claude.ai/artifact/HzsqaSR7acdtyPGgv3apz1 (option B, green).

- Single `style.css`, one column (`max-width: 44rem`), side gutter ≥ 16px.
- **Always dark** (single look, no light theme): `color-scheme: dark`.
  Tokens: `--bg #15171a`, `--fg #d9d6cf`, `--muted #8a877f`, `--rule #2a2d31`,
  `--accent #7ee08f`.
- Font: **JetBrains Mono** v2.304 (OFL), full woff2 files (Regular, SemiBold —
  they include the box-drawing glyphs `├─└`) self-hosted in `static/fonts/` with
  `OFL.txt`, `font-display: swap`; fallback
  `ui-monospace, "Cascadia Code", Consolas, Menlo, monospace`. No external requests.
- Sections are headed by a fake shell command, rendered as a real `<h2>` with the
  prompt `~/vmamore $ ` added by CSS `::before`:
  - pt: `whoami`, `cat sobre.md`, `ls experiencia/`, `cat formacao.md`
  - en: `whoami`, `cat about.md`, `ls experience/`, `cat education.md`
- `whoami` block: name (large, bold), headline · location (muted), links in accent.
- Experience: each company is `<dir>/` in accent (full `Name` in a `title`
  attribute) + span (muted, only for multi-role companies); roles listed with tree glyphs (`├─` for all but the
  last, `└─` for the last), title + dates/duration (muted), summary, and a tech
  line in muted prefixed by `# ` (full list, comma-separated).
- Language toggle top-left: `pt / en`, current language in bold accent.
- Footer: `© <year> Vinicius Mamoré`, then a comment line (`# ` prefix by CSS):
  pt `feito com F#, Giraffe.ViewEngine, Markdig, JetBrains Mono · hospedado no
  GitHub Pages · código-fonte`; en `built with … · hosted on GitHub Pages · source`.
  Each tool links to its site; the last item links to
  `https://github.com/vmamore/vmamore.github.io`.
- A blinking block caret at the end of the page; static when
  `prefers-reduced-motion: reduce`.
- No JavaScript, no images in v1 (favicon only).

## CLI and local dev

- `dotnet run --project src/Site -- build` → writes `_site/` (wipes it first).
- `dotnet run --project src/Site -- serve` → builds, then serves `_site/` on
  `http://localhost:5000` with a minimal `HttpListener` static file server.
  Rebuild by re-running (no file watching in v1).

## Deploy (GitHub Actions)

On push to `main` (and manual dispatch):
1. `actions/checkout`, `actions/setup-dotnet` (10.0.x)
2. `dotnet test`
3. `dotnet run --project src/Site -c Release -- build _site`
4. `actions/upload-pages-artifact` (`_site`) → `actions/deploy-pages`

Permissions: `pages: write`, `id-token: write`, `contents: read`.
Note: "present" durations only refresh on a new build; acceptable for v1.
